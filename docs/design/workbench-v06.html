runner 的超时是怎么算的？20 分钟从哪开始？
agent
withTimeout 包住 agent.whenIdle()，从「会话创建成功」开始计时，默认 20 分钟；超时后把两张图标 failed，会话不会被 kill。一次「更新」= 前端 POST → prefix 路由 → handleUpdate（git 快进 + 快照写台账）→ Runner.start → 后台 follow 等 agent 结束 → 解析产物标记 + 目录兜底 → 逐图回写 ready/failed → 页面轮询刷新。其中 domain 失败时两张图命运分开判定：结构图照样 ready（失败路径先看盘），领域图单独 failed，整条 run 记 failed。如果你只想要一张图，重画单图不会碰到另一张。
